# ft_printf

A reimplementation of `printf` in C as part of the 42 curriculum.

## Objective

Reproduce the behavior of the format conversions required by the project, with explicit handling of variadic arguments and output formatting.

## Features

- Format string parsing.
- Support for the conversions actually implemented in this repository.
- Tracking the number of characters written and handling edge cases.

## Technologies

- C
- Variadic functions (`stdarg.h`)
- String manipulation and formatting


## Author

Developed as part of the 42 curriculum.
